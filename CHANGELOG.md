# Changelog

## [0.1.0] - 2026-11-07

- Initialized the AppHub Tauri 2 / React desktop application.
- Added WinGet detection, search, installed package listing, update scan, install, uninstall, upgrade and source listing.
- Added local package favorites with add/remove operations and persistent storage in the application data directory.
- Added dark/light theme and primary application navigation.
- Added Windows CI and NSIS release workflow foundations.

This version is an early development build. CI validation and Windows installer verification are still in progress.
